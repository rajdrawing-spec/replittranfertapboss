**UI/UX Redesign Prompt for Replit**

---

Redesign the entire **TapasHub Business OS** UI/UX into a **premium, enterprise-grade SaaS application**. This is **only a UI/UX redesign**—do **not** modify any backend logic, APIs, database structure, routes, permissions, or functionality. Preserve all existing features and workflows while replacing the visual design with a modern, consistent design system.

### Design Direction

Create a clean, premium interface inspired by **Linear, Microsoft Teams, Notion, GitHub, Vercel Dashboard, Slack, Stripe, and Apple's Human Interface Guidelines**. The experience should feel fast, professional, minimal, and suitable for large enterprises.

### Core Principles

* Clean, modern, enterprise-focused design.
* Excellent visual hierarchy and readability.
* Consistent spacing using an **8px grid system**.
* No clutter or unnecessary decorative elements.
* Smooth micro-interactions (150–200ms).
* Fully responsive for desktop, tablet, and mobile.
* WCAG AA accessible contrast and typography.

### Visual Style

* **No soft shadows**
* **No neumorphism**
* **No glassmorphism**
* No excessive gradients or glow effects.
* Use clean borders, spacing, typography, and color contrast to create depth.
* Border radius: **14–16px**
* Thin borders (1px) for cards, inputs, dropdowns, modals, and panels.

Danger: `#EF4444`

Use TapasHub blue consistently across active states, buttons, links, notifications, and selected navigation items.

### Typography

Use **Inter** or **Geist** throughout the application.

Hierarchy:

* Page Title: 30px / SemiBold
* Section Heading: 22px
* Card Title: 18px
* Body Text: 15px
* Caption: 13px

Avoid thin font weights.

### Icons

Use **Lucide Icons** consistently.

* Size: 20–22px
* Uniform stroke width
* Modern, minimal appearance
