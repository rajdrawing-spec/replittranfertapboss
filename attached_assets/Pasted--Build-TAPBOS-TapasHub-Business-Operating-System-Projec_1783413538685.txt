# Build TAPBOS(TapasHub Business Operating System)

## Project Name

**TAPBOS (TapasHub Business Operating System)**

### Project Goal

Build a **professional, enterprise-grade business management platform** for TapasHub. This is **not** a CRM or ERP clone—it should be a clean, modern operating system that allows our team, investors, and administrators to manage all TapasHub brands from one secure place.

Do **not** replace or break any existing features. Refactor carefully and preserve current data wherever possible. Existing functionality should continue working while the new UI and architecture are introduced.

---

# Design Style

Create a premium interface inspired by modern business software.

Design inspiration:

* Linear
* Notion
* Slack
* Stripe Dashboard
* Google Workspace
* Vercel Dashboard

The interface must be:

* Minimal
* Modern
* Fast
* Responsive
* Mobile-first
* Tablet friendly
* Desktop friendly
* Easy for non-technical users
* Accessible with clear typography and spacing

Avoid clutter, excessive colors, unnecessary animations, and complex menus.
