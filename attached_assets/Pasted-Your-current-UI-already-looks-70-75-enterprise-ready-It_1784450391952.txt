## 11. Two-Panel Mobile Layout

On mobile, **never display both panels side by side** (for example, chat list + conversation, or product list + product details). This is what makes text too small and difficult to read.

Instead use a master-detail navigation pattern:

**Screen 1**

```
Product List
```

Tap a product →

**Screen 2**

```
Product Details
```

Add a back button to return to the list.

The same pattern should be used for:

* Chats → Conversation
* Employees → Profile
* Orders → Order Details
* Meetings → Meeting Info
* Files → File Preview

---

# 12. Tablet Optimization

Use responsive breakpoints:

* **Desktop (>1200px):** Sidebar + content + optional detail panel
* **Tablet (768–1199px):** Collapsible sidebar + content
* **Mobile (<768px):** Single screen with bottom navigation and drawer menu

# 16. AI Features

Keep AI visually distinct but consistent with the brand.

Add AI actions like:

* ✨ Rewrite Text

---

# 17. Notifications

Use toast notifications:

* Success → Green
* Warning → Yellow
* Error → Red
* Info → Blue

Include icons and auto-dismiss after a few seconds.

---

# 18. Accessibility

* Minimum 16px body text
* Touch targets at least 44×44px
* High contrast
* Keyboard navigation
* Visible focus indicators

---

# 19. Performance

* Lazy-load long tables
* Virtual scrolling for large datasets
* Skeleton loaders
* Progressive image loading

---

# 20. Motion

Use subtle animations (200–300ms):

* Fade-in dialogs
* Slide-in drawers
* Smooth hover states
* Button press feedback

Avoid excessive animations that slow down productivity.

---

# 21. Design Consistency

Create reusable components for:

* Buttons
* Inputs
* Tables
* Cards
* Modals
* Badges
* Avatars
* Empty states
* Loaders

Maintain consistent spacing using an **8px grid system**.

---

# 22. Overall Visual Goal

Your product should feel like a combination of:

* Slack (communication)
* Microsoft Teams (meetings)
* Notion (clean layouts)
* Linear (speed and polish)
* Stripe Dashboard (clarity)
* Atlassian Jira (enterprise workflows)

while maintaining the **Tapas Hub** identity with a **black, white, and blue** color palette inspired by your logo.

Following these guidelines will give TapBoss a modern, enterprise-grade experience that is easier to use on desktop, tablet, and especially on mobile, where switching from split views to single-screen master-detail navigation will greatly improve readability and usability.
